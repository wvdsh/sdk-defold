# Wavedash SDK for Defold

Connects Defold games to [Wavedash](https://wavedash.com).

## Install

Add a [release](https://github.com/wvdsh/sdk-defold/releases) zip to the Dependencies in your `game.project`:

```
https://github.com/wvdsh/sdk-defold/archive/refs/tags/<version>.zip
```

Then call `wavedash.init()` once your game is ready to play.

`example/` is a sample project. Docs: [docs.wavedash.com/engines/defold](https://docs.wavedash.com/engines/defold)
